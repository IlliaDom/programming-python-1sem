# Практична робота №46 (П21)

**Тема:** Поліморфізм, методи класу та статичні методи  
**Виконала:** Вовк Марія Віталіївна, група І-23  
**Дата народження:** 02.12.2008

## Файли
- `task1.py` — альтернативні конструктори, статичні методи та змінні класу.
- `task4.py` — поліморфізм для витрат, доходів і переказів.
- `data/expenses.csv` — витрати з практичної роботи 22.
- `data/expenses.json` — витрати з практичної роботи 36.
- `report_lab46.pdf` — звіт.

## Запуск у PowerShell
```powershell
python task1.py
python task4.py
```

У папку `data` потрібно скопіювати власні файли `expenses.csv` і `expenses.json` з попередніх практичних робіт, не змінюючи записи.

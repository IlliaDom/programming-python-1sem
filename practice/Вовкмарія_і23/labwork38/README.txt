Запуск у Windows PowerShell:
1. Перейдіть у папку lab38.
2. Створіть середовище:
   py -m venv .venv
3. Активуйте його:
   .\.venv\Scripts\Activate.ps1
4. Встановіть бібліотеку:
   python -m pip install -r requirements.txt
5. Запустіть завдання:
   python task1.py
   python task2.py
   python task3.py
   python task5.py

Завдання 4 — перевірка помилок:
   python task2.py --demo connection
   python task2.py --demo http
   python task2.py --demo timeout

У кожному запиті встановлено таймаут. HTTP-помилки перевіряються через
raise_for_status(), мережеві помилки обробляються requests.RequestException.

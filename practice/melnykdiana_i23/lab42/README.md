# Практична робота П19 — конструктори, деструктори та інкапсуляція

**Власниця гаманця:** Діана Мельник, група І-23  
**Витрати:** скопійовані з `expenses.csv` роботи 22.

У теці є `task1.py`–`task5.py`, CSV-файл та `report.pdf`.

Запуск із цієї теки:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
```

У `task4.py` встановлений демонстраційний бюджет 2 000 грн, бо точна сума місячного бюджету не була вказана. Перед здачею замініть значення `monthly_budget` на свій фактичний бюджет.

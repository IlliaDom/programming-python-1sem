Мета роботи
Навчитися виконувати HTTP-запити за допомогою бібліотеки requests, передавати параметри, перевіряти коди стану та обробляти JSON-відповіді. Ознайомитися з API Національного банку України та Open-Meteo, а також навчитися обробляти помилки мережі, таймаути й кешувати отримані дані.
Виконання роботи
Завдання 1. Перший запит
За допомогою requests надіслано запит до API Національного банку України. Програма перевіряє код відповіді, виводить тип вмісту та кількість валют, а також знаходить курси долара США й євро разом із датою їх встановлення.

Приклад виводу:
Мельник Діана, І-23
status: 200
Content-Type: application/json; charset=utf-8
currencies: [кількість валют із відповіді]
USD: [курс] UAH (дата: [дата відповіді API])
EUR: [курс] UAH (дата: [дата відповіді API])
Завдання 2. Витрати у валюті
Програма прочитала витрати з expenses.csv. Загальна сума у файлі — 1 975,00 грн. Курси USD і EUR отримуються окремими запитами до НБУ з параметром valcode. Суми у валюті обчислюються за курсами, отриманими від API.

Приклад виводу:
Мельник Діана, І-23
rate date: [дата відповіді API]
total: 1975.00 UAH = [сума] USD = [сума] EUR
Завдання 3. Погода в Олиці
Для запиту до Open-Meteo використано координати Олики: 50.72272, 25.81208. Програма отримує поточну температуру та швидкість вітру.

Приклад виводу:
Мельник Діана, І-23
Олика (50.72272, 25.81208): [температура] °C, wind [швидкість] km/h
Завдання 4. Обробка помилок
У програмі передбачено обробку трьох помилкових ситуацій: відсутності з’єднання, HTTP-помилки 404 і таймауту. Повідомлення виводиться в stderr, а програма завершується з кодом 1.

Приклади повідомлень:
Помилка з'єднання з API: ... (ConnectionError)
Код завершення: 1
HTTP-помилка відповіді API: ... (HTTPError)
Код завершення: 1
Час очікування відповіді вичерпано: ... (Timeout)
Код завершення: 1
Завдання 5. Кеш відповіді
Відповідь НБУ зберігається у файлі cache/rates.json разом із часом отримання. Якщо кешу менше години, програма використовує його. Інакше виконується новий запит до API.

Приклад виводу:
Мельник Діана, І-23
source: api (cache saved)
Під час повторного запуску в межах години:
Мельник Діана, І-23
source: cache (age ... s)
Відповіді на контрольні запитання
1. З чого складається HTTP-запит і HTTP-відповідь?
   Запит містить метод, адресу з параметрами, заголовки та, за потреби, тіло. Відповідь містить код стану, заголовки й тіло з даними.
2. Що означають коди 200, 404 і 500?
   200 — запит успішний. 404 — ресурс не знайдено. 500 — внутрішня помилка сервера.
3. Навіщо передавати параметри через params=?
   requests сам правильно додає та кодує параметри адреси. Це зменшує ризик помилок і робить код зрозумілішим.
4. Чому кожен запит повинен мати таймаут?
   Таймаут обмежує час очікування відповіді. Без нього програма може зависнути, якщо сервер не відповідає.
5. Чим requests.ConnectionError відрізняється від requests.HTTPError?
   ConnectionError означає, що не вдалося встановити з’єднання. HTTPError виникає, коли сервер відповів помилковим HTTP-кодом, наприклад 404.
6. Навіщо кешувати відповіді API і які ризики застарілого кешу?
   Кеш допомагає зменшити кількість запитів і пришвидшити роботу програми. Застарілий кеш може містити дані, які вже не відповідають поточним курсам або умовам, тому для нього встановлюють строк дії.
Висновок
Під час практичної роботи підготовлено програми для отримання курсів валют НБУ та погоди в Олиці, обчислення витрат у різних валютах, обробки мережевих помилок і збереження відповіді API в кеші. Навички роботи з HTTP-запитами та JSON можна використовувати для отримання й аналізу відкритих даних.

### Використані дані

Для роботи використано файл `expenses.csv` із попередньої роботи. Він містить 12 записів на загальну суму **1975 грн**. Для демонстрації порівняння з бюджетом використано 5000 грн — це значення можна замінити на власний бюджет.

### Завдання 1. Клас `Money`

Створено клас `Money`, який зберігає суму в цілих копійках. Реалізовано оператори додавання, віднімання, множення на число, рівність і порівняння. Для різних валют арифметичну операцію заборонено.

Результат роботи:

```text
Money(0.1) + Money(0.2) = 0.30 UAH
Money(0.1) + Money(0.2) == Money(0.3): True
0.1 + 0.2 == 0.3 для float: False
Віднімання: 6.75 UAH
Множення: 37.50 UAH
repr: Money(12.50, 'UAH')
Помилка різних валют: different currencies
```

Зберігання суми в копійках дає змогу уникнути похибок округлення, властивих типу `float`.

### Завдання 2. Сортування та сума

Суми з CSV перетворено на об’єкти `Money`, відсортовано від найменшої до найбільшої та підсумовано за допомогою `sum()`.

```text
Витрати за сумою, від меншої до більшої:
60.00 UAH, 60.00 UAH, 60.00 UAH, 85.00 UAH, 90.00 UAH, 150.00 UAH, 180.00 UAH, 200.00 UAH, 220.00 UAH, 250.00 UAH, 300.00 UAH, 320.00 UAH
Кількість записів: 12
Загальна сума: 1975.00 UAH
Money(10) + 5: TypeError: unsupported operand type(s) for +: 'Money' and 'int'
```

Другий аргумент у `sum(items, Money(0))` задає початкове значення суми правильного типу. Метод `__add__` повертає `NotImplemented` для непідтримуваного операнда, а Python генерує `TypeError`.

### Завдання 3. Колекція витрат

Створено клас `ExpenseBook`, який підтримує `len()`, перевірку категорії через `in`, перебір витрат, доступ за індексом, об’єднання книг оператором `+` і короткий текстовий звіт.

Витрати поділено на дві групи за днем місяця: перша половина — дні з 1-го по 15-те, друга половина — з 16-го до кінця місяця.

Після об’єднання книги містять усі 12 записів із CSV.

### Контрольні запитання

**1. Що таке спеціальні методи і як Python їх викликає?**  
Спеціальні методи визначають поведінку об’єкта у вбудованих операціях. Наприклад, вираз `a + b` викликає `a.__add__(b)`, а `len(book)` — `book.__len__()`.

**2. Чому гроші краще зберігати в копійках цілим числом?**  
Цілі числа точно представляють найменші грошові одиниці. Це допомагає уникнути похибок двійкового представлення `float`, наприклад різниці між `0.1 + 0.2` і `0.3`.

**3. Чим `__str__` відрізняється від `__repr__`?**  
`__str__` повертає зручне для читання людиною подання об’єкта. `__repr__` призначений для точнішого подання, корисного під час налагодження.

**4. Навіщо повертати `NotImplemented` замість генерації винятку?**  
`NotImplemented` повідомляє Python, що операнд цього типу не підтримується. Python може спробувати зворотний метод другого операнда, а якщо операція все одно неможлива — згенерує `TypeError`.

**5. Які методи потрібні, щоб об’єкт можна було відсортувати функцією `sorted`?**  
У цій роботі для порівняння елементів реалізовано метод `__lt__`, який відповідає за операцію «менше».

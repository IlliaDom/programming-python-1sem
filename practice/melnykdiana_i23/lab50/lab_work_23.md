### Використані дані

Для роботи використано файл `expenses.csv` із попередньої роботи. Він містить 12 записів про витрати. У прикладі залишено ім’я та групу зі зразка завдання — `Ivan Petrenko, PZ-11`; їх можна замінити на власні.

### Завдання 1. Абстрактний експортер

Створено абстрактний клас `Exporter` з абстрактними методами `export()` і `extension()`. Клас задає спільний контракт для всіх експортерів.

Спроба створити об’єкт `Exporter` спричиняє помилку, оскільки абстрактні методи не реалізовані:

```text
error: Can't instantiate abstract class Exporter without an implementation for abstract methods 'export', 'extension'
```

### Завдання 2. Три реалізації

Створено класи `CsvExporter`, `JsonExporter` і `TxtExporter`. Кожен реалізує методи абстрактного класу. Витрати з CSV-файлу експортовано в усі три формати одним циклом.

```text
Ivan Petrenko, PZ-11
saved: report.csv (12 records)
saved: report.json (12 records)
saved: report.txt (12 records)
```

Усі три файли містять однакові 12 записів.

### Завдання 3. Незавершена реалізація

Створено неповний клас HTML-експортера, який реалізує лише метод `extension()`. Python не дозволяє створити його об’єкт, доки не реалізований метод `export()`.

```text
Неповний експортер: Can't instantiate abstract class IncompleteHtmlExporter without an implementation for abstract method 'export'
saved: report.html (12 records)
```

Після реалізації `export()` програма створює HTML-таблицю витрат у файлі `report.html`.

### Завдання 4. Вибір формату користувачем

Формат експорту передається програмі як аргумент командного рядка. Якщо формат підтримується, програма створює відповідний файл. Для невідомого формату вона показує перелік доступних форматів і завершується з кодом `2`.

```text
saved: report.json (12 records)
Невідомий формат: xml. Доступні формати: csv, html, json, txt
Код завершення: 2
```

### Контрольні запитання

**1. Що таке абстрактний клас і чим він відрізняється від звичайного?**  
Абстрактний клас задає спільний контракт і може містити методи без повної реалізації. Його не можна безпосередньо створити як об’єкт, доки абстрактні методи не реалізовані в нащадку.

**2. Як оголосити абстрактний метод?**  
Потрібно імпортувати `abstractmethod` з модуля `abc` і позначити ним метод класу, який успадковує `ABC`.

**3. Чому не можна створити об’єкт абстрактного класу?**  
Абстрактний клас може містити методи без реалізації. Python вимагає створити клас-нащадок і реалізувати в ньому всі абстрактні методи.

**4. Що станеться, якщо нащадок реалізує не всі абстрактні методи?**  
Такий нащадок залишиться абстрактним. Спроба створити його об’єкт спричинить помилку `TypeError`.

**5. Як абстрактні класи пов’язані з принципом відкритості/закритості (SOLID)?**  
Програма працює зі спільним контрактом `Exporter`. Нові формати можна додавати окремими класами, не змінюючи основний цикл експорту. Це дає змогу розширювати програму без змін її наявної логіки.
